# QUY CHUẨN ĐA NGÔN NGỮ (I18N: TIẾNG VIỆT & TIẾNG ANH)
> **Phạm vi:** Toàn bộ Frontend (Svelte 5 Components, Services, Toasts, Modals) & Thông điệp người dùng.

Tất cả các AI Agent và lập trình viên khi phát triển tính năng cho FlowGit **bắt buộc tuân thủ 100%** các quy tắc dưới đây.

---

## 🎯 1. NGUYÊN TẮC CỐT LÕI (CORE PRINCIPLES)

1. **Bắt buộc Song ngữ Toàn diện (Vietnamese & English):**
   - Ứng dụng hỗ trợ 2 ngôn ngữ chính thức: **Tiếng Việt (`vi`)** và **Tiếng Anh (`en`)**.
   - Mặc định khởi tạo ngôn ngữ dựa trên cài đặt đã lưu trong `localStorage` hoặc ngôn ngữ hệ thống (`navigator.language`).

2. **Nghiêm cấm Hardcode Text UI:**
   - Tuyệt đối không viết text thô (raw string) tiếng Việt hay tiếng Anh trực tiếp trong template Svelte (`.svelte`) hoặc logic xử lý (`.ts`).
   - Mọi chuỗi ký tự hiển thị tới người dùng bao gồm:
     - Nhãn nút bấm (Buttons, Links, Actions)
     - Tiêu đề, mô tả (Headings, Subheadings, Descriptions)
     - Placeholder input, Label form
     - Tooltip, Badge text, Context Menu items
     - Hộp thoại cảnh báo, Modal confirmations
     - Toast notifications (Success, Error, Warning, Info)
     - Mô tả lỗi thân thiện với người dùng (User-facing error messages)
   - **Phải được gọi qua hàm dịch `localeState.t(...)`**.

---

## 📂 2. CẤU TRÚC TỆP TIN VÀ QUẢN LÝ TỪ ĐIỂN

Hệ thống i18n được tổ chức chặt chẽ tại:

```
src/lib/
├── i18n/
│   ├── index.ts               # Helper getNestedTranslation, interpolate, types
│   ├── vi.ts                  # Re-export tiếng Việt
│   ├── en.ts                  # Re-export tiếng Anh
│   └── locales/
│       ├── vi/                # TranslationSchema gốc & Từ điển Tiếng Việt module hóa (navigation, graph, common...)
│       └── en/                # Từ điển Tiếng Anh module hóa đối ứng 100%
└── state/
    └── localeState.svelte.ts  # Reactive State Store (localeState.t, localeState.locale)
```

- **`src/lib/i18n/locales/vi/`**: Định nghĩa kiểu `TranslationSchema` tại `index.ts`. Đây là từ điển gốc (source of truth).
- **`src/lib/i18n/locales/en/`**: Từ điển tiếng Anh, bắt buộc phải có cấu trúc cây key và số lượng key khớp 100% với `vi/`.

## 💻 3. HƯỚNG DẪN SỬ DỤNG TRONG CODE

### A. Sử dụng trong Svelte 5 Component:
```svelte
<script lang="ts">
  import { localeState } from '$lib/state/localeState.svelte';
</script>

<!-- 1. Text tĩnh -->
<h2>{localeState.t('workingTree.stagedChanges')}</h2>

<!-- 2. Attributes (Title, Placeholder, Tooltip) -->
<input
  type="text"
  placeholder={localeState.t('commit.placeholder')}
  title={localeState.t('toolbar.filterTip')}
/>

<!-- 3. Nội suy biến động (Dynamic Interpolation) -->
<!-- Định nghĩa trong file locale: "syncCount": "Đang đồng bộ {count} commits..." -->
<p>{localeState.t('statusBar.syncCount', { count: 5 })}</p>
```

### B. Sử dụng trong Toast Notifications & TypeScript Services:
```typescript
import { localeState } from '$lib/state/localeState.svelte';
import { toastState } from '$lib/state/toastState.svelte';

// Thông báo thành công
toastState.success(localeState.t('toasts.branchCreatedSuccess', { name: branchName }));

// Thông báo lỗi
toastState.error(localeState.t('toasts.conflictDetected'));
```

## 🔄 4. QUY TRÌNH KHI THÊM HOẶC CHỈNH SỬA UI (SYNC WORKFLOW)

Khi tạo mới một Component, Modal, hoặc bổ sung chuỗi ký tự hiển thị:

1. **Bước 1 (Định nghĩa Key Tiếng Việt):**
   Mở `src/lib/i18n/locales/vi.ts`, tìm nhóm chức năng phù hợp (hoặc tạo nhóm mới) và bổ sung key với bản dịch Tiếng Việt tự nhiên, chính xác về thuật ngữ Git.
2. **Bước 2 (Đồng bộ Key Tiếng Anh):**
   Mở `src/lib/i18n/locales/en.ts`, bổ sung chính xác key đó với bản dịch Tiếng Anh theo thuật ngữ quốc tế chuẩn của Git client (như GitKraken, Sublime Merge).
3. **Bước 3 (Gọi trong Component):**
   Truyền key vào `localeState.t('nhom.tenKey')`. Trình biên dịch TypeScript sẽ tự động gợi ý và kiểm tra tính hợp lệ của key nhờ `TranslationKey`.
