# ⚡ FlowGit: Git Client Đột Phá — Giới Thiệu Toàn Diện 18 Phân Khu Tính Năng, Kiến Trúc Rust & Lý Do Vượt Trội Hơn Thị Trường

> *Lõi Rust Native • Đồ Thị 60 FPS • Kéo Thả Rebase • Thùng Rác 48h Chống Mất Mã Nguồn*

Nhiều năm qua, các lập trình viên thường bị kẹt giữa 2 sự lựa chọn:
1. **Dòng lệnh Terminal (CLI):** Cực kỳ mạnh mẽ nhưng cú pháp khó nhớ, tải nhận thức cao, thiếu trực quan và luôn nơm nớp lo sợ bấm nhầm một lệnh `git reset --hard` là mất trắng code.
2. **Các Git GUI hiện có trên thị trường:** Hoặc là các app giao diện cũ kỹ từ thập niên 2010, hoặc là các app Electron nặng nề (như GitKraken) ngốn tới **1.2 GB RAM**, bắt trả phí thuê bao hàng năm đắt đỏ, và nếu lỡ bấm "Discard Changes" thì code uncommitted vẫn **mất vĩnh viễn**.

**FlowGit** ra đời để giải quyết triệt để sự đánh đổi đó. Đây là ứng dụng quản lý mã nguồn Git thế hệ mới, đa nền tảng, được xây dựng hoàn toàn trên nền tảng **Tauri v2**, lõi **Rust Native (libgit2)** và **Svelte 5 Runes**.

Bài viết này là cẩm nang giới thiệu chi tiết nhất về **toàn bộ 18 phân khu tính năng**, **hơn 40 nghiệp vụ Git nâng cao**, kiến trúc kỹ thuật bên dưới và lý do vì sao FlowGit vượt trội hơn hẳn các công cụ hiện nay.

# 🏛️ 6 Trụ Cột Kỹ Thuật & 18 Phân Khu Tính Năng Chi Tiết

FlowGit không chỉ là một lớp giao diện tô vẽ cho các câu lệnh CLI. Đây là một bộ công cụ kỹ thuật toàn diện được tổ chức thành **6 Trụ Cột Cốt Lõi**:

---

## 📊 TRỤ CỘT 1: Động Cơ Đồ Thị & Lịch Sử Commit Siêu Tốc

### 1. Đồ Thị Commit Sống Động (Khóa Cứng 60 FPS)
Vẽ đồ thị nhánh phức tạp (Directed Acyclic Graph - DAG) với hàng trăm làn rẽ nhánh là tác vụ ngốn rất nhiều tài nguyên. Các app thông thường dùng thẻ SVG hoặc DOM HTML khiến trình duyệt đơ cứng khi mở dự án lớn.
- FlowGit giao tác vụ nén làn và tính toán đường cong Bézier cho luồng đa nhân **Rust `rayon`**.
- Toàn bộ khâu vẽ giao diện được đưa vào **`OffscreenCanvas` chạy trong Web Worker độc lập (`graphWorker.ts`)**.
- Luồng UI chính (Main-thread) hoàn toàn không bị ảnh hưởng, giữ vững tốc độ **60 FPS** dù repo có 100 hay 100.000 commits.

### 2. Radar Mini-Map & Điều Hướng Timeline
Bản đồ thu nhỏ nằm dọc theo đồ thị, cho phép bạn kéo thanh trượt radar lướt qua nhiều năm lịch sử commit và nhảy thẳng tới điểm rẽ nhánh mong muốn trong 1 tích tắc.

### 3. Mô Phỏng Ảo Trước Khi Thả (In-Memory Ghost Preview)
Khi kéo một commit hoặc một nhánh thả vào nhánh khác:
- FlowGit tự động chạy dry-run mô phỏng ngầm trong RAM bằng Rust *ngay khi bạn đang giữ chuột*.
- Nếu sắp có xung đột (conflict), điểm thả sẽ phát sáng màu hổ phách kèm cảnh báo.
- Nếu gộp sạch sẽ (fast-forward), điểm thả sẽ sáng xanh lục. Bạn biết trước kết quả **trước khi** thả chuột!

### 4. Studio Interactive Rebase Trực Quan
Không còn phải đánh vật với trình soạn thảo Vim trong terminal:
- Kéo thả các nút commit để đổi thứ tự.
- Bấm vào huy hiệu hành động để chuyển đổi giữa `Pick`, `Reword`, `Drop`, `Squash`, và `Fixup`.
- Chọn nhiều commit và nhấn **`S`** để gộp (Squash) tức thì kèm tổng hợp commit message.

### 5. Chuỗi Stacked Commits & Ghim Nhánh Yêu Thích
- Quản lý và tái cấu trúc chuỗi commit phụ thuộc trước khi đẩy lên upstream PR.
- Đánh dấu sao (⭐) để ghim các nhánh quan trọng (`main`, `staging`, `production`) lên đầu thanh bên, và ẩn (👁️) các nhánh tính năng cũ.

## 🛡️ TRỤ CỘT 2: Động Cơ An Toàn Tuyệt Đối (No-Fear Git)

![Thùng Rác Safe Discard 48h](https://raw.githubusercontent.com/longgoll/flow-git/main/website/assets/flowgit_trash.png)

### 6. Thùng Rác SQLite 48 Giờ (Safe Discard Engine)
**Nỗi sợ số 1 của mọi lập trình viên:** Bấm nhầm *"Discard Changes"* trên các file chưa commit. Trong Git tiêu chuẩn, dữ liệu đó bị xóa vĩnh viễn khỏi ổ cứng.
- FlowGit chặn trước mọi hành vi discard.
- Toàn bộ nội dung tệp và từng khối diff (hunk) bị discard đều được tự động snapshot vào **SQLite database cục bộ**.
- Mở **Trash Inspector (48h)**, xem trước diff và bấm **Khôi phục (Restore)**. Dữ liệu của bạn được cứu sống 100% trong 1 giây!

![Reflog Time Machine](https://raw.githubusercontent.com/longgoll/flow-git/main/website/assets/flowgit_timemachine.png)

### 7. Cỗ Máy Thời Gian `Ctrl + Z` (Reflog Time Machine)
- FlowGit duy trì một nhật ký giao dịch Action Journal liên tục.
- Bất kỳ thao tác sai lầm nào (reset nhầm, checkout sai, rebase lỗi, lỡ áp stash sai), bạn chỉ việc bấm: **`Ctrl + Z`** (hoặc `Cmd + Z` trên macOS).
- FlowGit tính toán giao dịch nghịch đảo, cập nhật lại con trỏ reflog và đưa workspace về trạng thái cũ an toàn.

### 8. Vệ Sĩ Xử Lý Tình Huống Oái Oăm & Bác Sĩ Cứu Hộ Git (F1 Playbook)
- **Index Lock Deadlock Hunter:** Tự động phát hiện và giải phóng các tệp `.git/index.lock` bị treo do tiến trình CLI bị crash hoặc do phần mềm diệt virus giữ lại.
- **Windows File Lock Guard:** Cảnh báo trước khi tiến trình khác (như VS Code, TypeScript server) đang khóa file để tránh lỗi checkout dở dang.
- **Pre-Commit Secret Blocker:** Tự động quét và ngăn chặn commit các file chứa bí mật (`.env`, private key `id_rsa`) hoặc các file dung lượng quá lớn (> 50MB).
- **Bác sĩ cứu trợ Git Emergency Doctor:** Sửa lỗi 1-chạm khi rơi vào Detached HEAD, rebase bị treo giữa chừng hoặc lỗi tham chiếu hỏng.

## 🔍 TRỤ CỘT 3: Soi Mã Nguồn Monaco Diff & Giải Quyết Xung Đột

![Monaco Split Diff](https://raw.githubusercontent.com/longgoll/flow-git/main/website/assets/flowgit_diff_split.png)

### 9. Trình Xem Diff Monaco (Split & Unified)
Tích hợp trực tiếp **Monaco Editor** (trình biên soạn lõi của VS Code):
- Hỗ trợ tô màu cú pháp (Syntax Highlighting) cho hơn 100 ngôn ngữ lập trình.
- Hai chế độ: **Split Diff** (so sánh 2 cột song song) và **Unified Diff** (hiển thị inline).
- Tích hợp Minimap thu nhỏ và công tắc ẩn hiện khoảng trắng thừa.

### 10. Stage Từng Dòng & Từng Khối Mã
- Tạo nên các commit tinh gọn, chuẩn chỉ.
- Nhấp chuột vào bất kỳ dòng nào hoặc khối diff nào trong Monaco Diff và bấm phím cách **`Space`** để Stage hoặc Unstage.
- Xóa bỏ các dòng rác trực tiếp trong trình diff (vẫn được bảo vệ an toàn bởi Thùng rác 48h).

![4-Pane Conflict Resolver](https://raw.githubusercontent.com/longgoll/flow-git/main/website/assets/flowgit_conflicts.png)

### 11. Bộ Xử Lý Xung Đột 4-Pane 3-Way Monaco
Không bao giờ phải nhìn thấy những ký tự `<<<<<<< HEAD` khó hiểu nữa:
- **Ours (Nhánh hiện tại của bạn)** ở bên trái.
- **Base (Điểm chung)** ở giữa.
- **Theirs (Nhánh được gộp vào)** ở bên phải.
- **Kết quả xem trước (Result Preview)** ở phía dưới cùng với đầy đủ syntax highlighting trực tiếp.
- Bấm 1 chạm *"Lấy của ta (Take Ours)"*, *"Lấy của họ (Take Theirs)"*, hoặc chọn lọc từng dòng mã riêng lẻ.

### 12. Trình Dò Lỗi Hồi Quy Visual Git Bisect
Tìm kiếm commit gây ra lỗi trong số hàng trăm commit:
- Trình wizard Git Bisect chia đôi đồ thị commit trực quan.
- Tự động checkout vào commit ở giữa, cho phép bạn test và bấm nút **"Tốt (Pass)"** hoặc **"Lỗi (Fail)"**.
- Xác định chính xác commit gây lỗi trong vài phút thay vì mò mẫm hàng giờ.

## 🗂️ TRỤ CỘT 4: Nghiệp Vụ Git Nâng Cao & Dự Án Monorepo

![Repository Explorer](https://raw.githubusercontent.com/longgoll/flow-git/main/website/assets/flowgit_explorer.png)

### 13. Khám Phá File Repo & Git Blame Tương Tác
- **Tree Explorer:** Duyệt cây thư mục và đọc mã nguồn tại bất kỳ commit nào trong quá khứ mà không cần phải checkout làm bẩn working directory.
- **So sánh 2 Commit bất kỳ:** Chọn 2 commit hoặc 2 nhánh để xem diff toàn bộ các file thay đổi.
- **Interactive Blame:** Di chuột qua từng dòng mã để biết ai là tác giả, commit nào, ngày nào và nhảy thẳng tới vị trí đó trên đồ thị.
- **Lịch sử tệp đơn lẻ:** Xem toàn bộ dòng thời gian biến đổi của một file qua nhiều năm.

### 14. History Nuker (Bộ Xóa Dữ Liệu Nhạy Cảm 1-Chạm)
Lỡ commit mật khẩu sản xuất, API key hoặc file video 200MB từ nhiều commit trước?
- Mở **History Nuker**, nhập tên tệp hoặc đường dẫn và bấm **Thanh Trừng (Nuke)**.
- FlowGit quét và xóa sạch tệp đó trên toàn bộ 100% lịch sử Git trong vài giây, tự động dọn dẹp và repack repository mà không cần lệnh phức tạp.

### 15. Studio Git Worktrees Song Song & Quick Hotfix 1-Chạm
- **Worktrees Studio:** Làm việc đồng thời trên nhiều nhánh ở các thư mục vật lý độc lập. Không cần stash, không cần chuyển nhánh, không phải build lại node_modules.
- **1-Click Quick Hotfix:** Có bug production khẩn cấp? Bấm **Quick Hotfix** — FlowGit tự tạo thư mục worktree tạm từ `main`, bạn sửa bug, commit, push, và hệ thống tự động dọn dẹp thư mục sau khi hoàn tất.

### 16. Monorepo Sparse Checkout & Git LFS Hub
- **Sparse Checkout Studio:** Cấu hình Git Cone Mode trực quan để chỉ tải về các thư mục dự án bạn cần làm việc trong các kho monorepo khổng lồ.
- **Git LFS Engine:** Quản lý file nhị phân dung lượng lớn, xem trạng thái khóa file từ xa và mở khóa trực tiếp trên giao diện.
- **Git Submodules Hub:** Khởi tạo, cập nhật đệ quy và đồng bộ các submodule con trực quan.

## 🌐 TRỤ CỘT 5: Kết Nối Đám Mây, CI/CD & Bảo Mật

### 17. Review GitHub PR & Giám Sát Actions CI/CD In-App
Giữ trình duyệt web đóng lại:
- **GitHub Pull Requests:** Duyệt danh sách PR, xem Monaco diff, viết nhận xét inline, duyệt và merge trực tiếp trong FlowGit.
- **GitHub Actions Runner:** Theo dõi các workflow CI/CD đang chạy real-time, xem cây trạng thái từng bước và stream log terminal ANSI trực tiếp.

### 18. Bảo Mật, Ký Commit GPG/SSH & Đa Danh Tính
- **Ký Commit GPG & SSH:** Ký số cho commit và hiển thị huy hiệu Verified chuẩn doanh nghiệp.
- **Native OS Keychain:** Lưu trữ token OAuth GitHub trong **Windows Credential Manager** và **macOS Keychain**.
- **Chuyển đổi danh tính theo Repository:** Gắn riêng tên tác giả, email (`personal@gmail.com` vs `work@company.com`) và SSH key riêng cho từng repo để tránh nhầm lẫn danh tính công việc.
