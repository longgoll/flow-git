# ⚡ FlowGit v0.1.3: Git Client Lõi Rust & Svelte 5 Siêu Tốc (<85MB RAM) & Triết Lý "No-Fear Git"

> **Bài viết giới thiệu chi tiết, so sánh hiệu năng và giải quyết các bài toán "ác mộng" mà GitKraken, SourceTree hay GitHub Desktop chưa giải quyết được.**

---

Mỗi lập trình viên chúng ta đều dùng Git hàng ngày. Nhưng chắc chắn ai cũng từng trải qua những khoảnh khắc "toát mồ hôi hột":
- Vừa viết xong 300 dòng thuật toán chưa kịp commit, vô tình bấm nhầm **"Discard All Changes"** và code **biến mất vĩnh viễn không dấu vết**.
- Rebase nhầm nhánh hoặc lỡ tay `git reset --hard` sai target khiến lịch sử commit bị rối loạn, phải còng lưng gõ `git reflog` trong terminal để mò mẫm.
- Mở một ứng dụng Git GUI quen thuộc lên thì ngốn ngay **1.2 GB RAM**, 6 tiến trình Chromium chạy ngầm làm máy nóng ran và quạt kêu như trực thăng.
- Mở repo công ty 40.000 commits thì giao diện đơ lag, cuộn đồ thị giật cục dưới 15 FPS.

Đó là lý do **FlowGit** ra đời — một Git client thế hệ mới được xây dựng từ nền tảng **Tauri v2**, lõi **Rust Native (`libgit2`)** và **Svelte 5 Runes**.

## 🛡️ Vấn Đề #1: "Bấm Nhầm Discard = Mất Code Vĩnh Viễn" (Đã Giải Quyết Triệt Để!)

### Cơn ác mộng:
Bạn dành cả buổi chiều chỉnh sửa code. Khi chuẩn bị commit, bạn stage những file cần thiết, rồi nhấn *"Discard Unstaged Changes"* để dọn dẹp các dòng console.log debug.
Đột nhiên bạn nhận ra: **đoạn code logic hay nhất lại nằm ở phần vừa bị Discard**.

Trên **tất cả các app Git thông thường**, các dòng uncommitted này bị xóa thẳng khỏi ổ cứng. Chúng không nằm trong `git reflog`, không có trong thùng rác Windows. **Bạn mất trắng công sức cả ngày!**

### Giải pháp của FlowGit: Thùng Rác SQLite 48 Giờ (Safe Discard Engine)
Trước khi xóa bất kỳ byte nào trên đĩa:
1. FlowGit tự động trích xuất snapshot các hunks hoặc file sắp discard.
2. Lưu trữ an toàn vào **SQLite database cục bộ**.
3. Nếu lỡ tay bấm nhầm, bạn chỉ cần mở **Trash Inspector (48h)** ➔ Xem diff trực quan ➔ Bấm **Khôi phục (Restore)**. Mã nguồn của bạn lập tức trở lại nguyên vẹn trong 1 giây!

## ⏳ Vấn Đề #2: Rebase Bị Lỗi, Reset Nhầm Nhánh (`Ctrl + Z` Time Machine)

### Cơn ác mộng:
Thực hiện rebase hoặc reset nhầm branch, rơi vào trạng thái Detached HEAD hoặc commit lộn xộn. Bạn phải mở terminal, gõ `git reflog`, dò từng dòng mã SHA phức tạp và cầu may.

### Giải pháp của FlowGit: Cỗ Máy Thời Gian `Ctrl + Z`
FlowGit ghi nhận nhật ký thao tác transactional Action Journal. Bất kỳ tác vụ nào (reset, checkout, rebase, di chuyển branch, stash) nếu làm sai, bạn chỉ cần nhấn:

**`Ctrl + Z` (hoặc `Cmd + Z` trên macOS)**

FlowGit tự động tính toán con trỏ reflog ngược lại và hoàn tác trạng thái nhánh về vị trí ban đầu ngay lập tức.

## ⚡ Vấn Đề #3: Electron Ăn Cả GB RAM (FlowGit < 85MB Nhờ Rust Native)

### Cơn ác mộng:
Tại sao một công cụ duyệt Git và xem văn bản lại cần ngốn tới 1.2 GB RAM và mở 6 tiến trình Chromium? Vì các app Electron phải đóng gói cả trình duyệt web lẫn Node.js runtime.

### Giải pháp của FlowGit:
- **Backend:** 100% **Rust Native (2024)** gắn trực tiếp thư viện C `libgit2`. Không cần spawn lệnh terminal `git.exe`, tối ưu zero-copy.
- **Frontend:** **Svelte 5** tối tân với Runes (`$state.raw` triệt tiêu chi phí Proxy overhead cho mảng hàng chục nghìn commits).
- **Runtime:** **Tauri v2** tận dụng webview bản địa của hệ điều hành, kích thước installer chỉ vỏn vẹn **~30MB**.

## 🚀 Vấn Đề #4: Đồ Thị Bị Lag Trên Monorepo Lớn (OffscreenCanvas Web Worker)

Nhiều client vẽ đồ thị commit bằng các thẻ SVG hoặc HTML DOM. Khi repository có trên 30.000 commit, trình duyệt phải liên tục tính toán lại cây DOM làm giao diện bị đơ cứng.

FlowGit tách biệt hoàn toàn việc render:
1. **Rust đa luồng (`rayon`)** tính toán topology nhánh và đường cong Bézier song song trên các nhân CPU.
2. Giao diện chuyển toàn bộ tác vụ vẽ sang **`OffscreenCanvas` chạy trong Web Worker (`graphWorker.ts`)**.
3. Luồng UI chính (Main-thread) hoàn toàn không bị ảnh hưởng, giữ vững **60 FPS** mượt mà cho dù repo có tới 100.000 commit.

## ⚔️ Vấn Đề #5: Ác Mộng Giải Quyết Xung Đột (Bộ Xử Lý 4-Pane 3-Way Monaco)

Sửa các đoạn xung đột `<<<<<<< HEAD`, `=======`, `>>>>>>>` bằng tay rất dễ xóa nhầm code của đồng nghiệp.

FlowGit tích hợp trình giải quyết xung đột **4-Pane 3-Way Resolver** với lõi **Monaco Editor** (trình biên soạn của VS Code):
- **Ours (Nhánh của bạn)**
- **Base (Điểm chung)**
- **Theirs (Nhánh được gộp)**
- **Kết quả xem trước (Result Preview)**

Bạn có thể bấm 1 click để chọn toàn bộ bên của mình/bên kia, hoặc chọn từng khối code với đầy đủ syntax highlighting.

## 🧰 Các Tính Năng Nâng Cao Mà Thông Thường Phải Gõ Terminal

1. **Git Worktrees Studio:** Làm việc đồng thời trên nhiều branch ở các thư mục riêng biệt mà không cần `git stash`. Có bug hotfix gấp? Tạo worktree sửa xong xóa trong 1 nốt nhạc.
2. **Interactive Rebase & Kéo Thả Commit:** Đổi thứ tự commit, Squash (`S`), xóa hoặc sửa commit message chỉ bằng thao tác kéo thả.
3. **Mô Phỏng Ghost Preview:** Khi kéo branch thả vào nhánh khác, FlowGit tự động chạy dry-run mô phỏng ngầm trong RAM và báo trước có bị conflict hay không trước khi bạn thả chuột!
4. **History Nuker:** Lỡ commit file `.env` hoặc API key nhạy cảm từ 20 commit trước? Xóa sạch dấu vết trên 100% lịch sử Git chỉ với 1 click.
5. **Universal Command Palette (`Ctrl + K`):** Thực thi hơn 50 lệnh Git bằng tìm kiếm mờ (fuzzy-search) mà không cần chạm chuột.

## 💻 Tech Stack Hiện Đại

- **Lõi Backend:** Rust (2024) + `git2-rs` + `rayon` + `tokio`.
- **Desktop Shell:** Tauri v2.
- **Giao diện Frontend:** Svelte 5 (Runes) + Tailwind CSS v4.
- **Editor:** Monaco Editor & Monaco Diff Editor.
- **Cơ sở dữ liệu an toàn:** SQLite cục bộ (qua `rusqlite`).
- **Bảo mật:** Lưu token an toàn trong Windows Credential Manager / macOS Keychain.
- **Đa ngôn ngữ:** Hỗ trợ song ngữ hoàn chỉnh 100% Tiếng Việt & Tiếng Anh.
