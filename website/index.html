Tại Sao FlowGit Vượt Trội?

Mọi tính năng đều được chế tác để giải quyết nỗi đau lớn nhất của lập trình viên khi làm việc với Git hàng ngày.

🛡️

Safe Discard 48h & Time Machine (Ctrl+Z)

Không bao giờ sợ mất code. Mọi đoạn code discard đều được tự động snapshot vào SQLite 48h. Hoàn tác mọi thao tác nguy hiểm (Reset, Rebase hỏng) tức thì chỉ với Ctrl+Z.

📊

Living Commit Graph 60 FPS Locked

Đồ thị động học dựng bằng OffscreenCanvas và Web Worker cách ly hoàn toàn khỏi UI thread. Thuật toán Rayon song song đảm bảo cuộn mượt mà ngay cả với repo kernel.

🔀

Kéo Thả Rebase & In-Memory Ghost Preview

Đổi thứ tự commit, bôi đen gộp (Squash) chỉ bằng kéo thả. Thuật toán Ghost Preview mô phỏng in-memory cảnh báo conflict trước khi bạn nhả chuột.

⚔️

Trình Xử Lý Xung Đột 4 Khung Hình

Phân tách rõ ràng Ours, Base, Theirs và Result. Nhận từng khối mã trực quan 1-click kết hợp sức mạnh highlight cú pháp của Monaco Editor (chuẩn VS Code).

🐙

GitHub Pull Request Workspace

Duyệt PR, đọc diff Monaco, theo dõi CI/CD Actions, checkout nhánh PR và merge trực tiếp trong app mà không cần mở trình duyệt.

🐞

Visual Git Bisect Wizard

Tự động phân đôi lịch sử commit và dẫn dắt bạn qua giao diện trực quan để truy vết commit gây bug chỉ sau 4 - 5 bước kiểm tra.

🧹

History Nuker (Tẩy Xóa File Mật)

Xóa vĩnh viễn file nhạy cảm lỡ commit (.env, API keys, file binary nặng hàng trăm MB) khỏi toàn bộ lịch sử Git chỉ với vài cú nhấp chuột.

🔄

Tự Động Cập Nhật 0 Đồng (Zero-VPS)

Tích hợp công nghệ cập nhật ngầm Tauri v2 ký số bằng mật mã Ed25519, phân phối qua GitHub Releases an toàn tuyệt đối và miễn phí trọn đời.

⚔️ Trực Quan Hóa Xung Đột

Trình Giải Quyết Xung Đột 3 Khung Hình Chuẩn Monaco

Không còn phải đoán mò giữa hàng đống dấu <<<<<<< HEAD trong terminal. FlowGit chia tách trực quan nhánh Hiện tại (Ours), nhánh Nhập vào (Theirs) và khung Kết quả cuối cùng với sự hỗ trợ của AI Auto-Merge.

  • ✓ Chọn nhanh 1-Click "Take All Ours" hoặc "Take All Theirs"
  • ✓ Highlight cú pháp chuyên nghiệp thừa hưởng từ VS Code (Monaco Editor)
  • ✓ AI tự động đọc hiểu ngữ cảnh và hợp nhất code an toàn
🛡️ An Toàn Tuyệt Đối

Thùng Rác Safe Discard 48h & Time Machine (Ctrl+Z)

Thao tác Git không còn là nỗi sợ mất code. Mọi tệp hoặc đoạn mã bạn bấm Discard đều được bí mật snapshot vào SQLite cục bộ trong 48 giờ. Bạn có thể xem trước diff và phục hồi tức thì.

  • ✓ Lưu trữ SQLite tự dọn dẹp sau 48h mà không ngốn dung lượng ổ đĩa
  • ✓ Hoàn tác Time Machine bằng phím tắt toàn năng Ctrl + Z
  • ✓ Xem trước diff của từng snapshot trước khi bấm Phục Hồi

⚡ Hướng Dẫn Chi Tiết

Nên Tải File Nào & Cài Đặt Ra Sao?

Giải thích chi tiết công dụng của từng định dạng tệp và hướng dẫn cài đặt chuẩn xác trong 30 giây cho mọi hệ điều hành.

Các Tệp Tải Về Cho Windows
..._x64-setup.exe ★ Khuyên Dùng

Trình cài đặt tự động NSIS (~8 MB). Tự tạo shortcut trên Desktop & Start Menu, tích hợp gỡ cài đặt sạch sẽ và hỗ trợ tự động cập nhật ngầm.

..._x64_en-US.msi Doanh Nghiệp / IT

Gói Windows Installer chính thống (~10 MB), phù hợp triển khai đồng loạt trong môi trường công ty thông qua Group Policy hoặc Active Directory.

3 Bước Cài Đặt Trên Windows
1
Tải & Khởi Chạy
Tải file FlowGit_..._x64-setup.exe về và nhấp đúp chuột để mở.
2
Xử Lý Màn Hình SmartScreen
Nếu Windows Defender hiện thông báo xanh "Windows protected your PC": hãy nhấn "More info" (Thông tin thêm) ➔ chọn "Run anyway" (Vẫn chạy).
3
Hoàn Tất & Sử Dụng
Ứng dụng cài đặt hoàn tất chỉ trong 3 giây và tự động mở lên sẵn sàng cho bạn sử dụng!
💡 Tại sao có thông báo SmartScreen? Do FlowGit là phần mềm mã nguồn mở mới phát hành nên Windows chưa lưu danh tiếng. Ứng dụng an toàn 100% và không chứa bất kỳ phần mềm gián điệp nào.
Các Tệp Tải Về Cho macOS
..._aarch64.dmg ★ Apple Silicon

Tối ưu native cho toàn bộ máy Mac chạy chip M1, M2, M3, M4 với hiệu năng cao nhất và thời lượng pin tối đa.

..._x86_64.dmg Intel Mac

Dành cho các dòng máy Mac đời trước chạy vi xử lý Intel Core.

Cài Đặt Trên macOS
1
Mở File .dmg & Kéo Vào Applications
Mở tệp .dmg tải về, kéo biểu tượng FlowGit thả vào thư mục Applications.
2
Xử Lý Cảnh Báo Gatekeeper (Nếu Có)
Nếu macOS báo "App can't be opened because it is from an unidentified developer": vào System Settings (Cài đặt) ➔ Privacy & Security (Quyền riêng tư) ➔ cuộn xuống bấm "Open Anyway" (Vẫn mở).
Các Tệp Tải Về Cho Linux
..._amd64.deb ★ Ubuntu / Debian

Gói cài đặt chuẩn cho Ubuntu, Debian, Linux Mint, Pop!_OS. Tích hợp sâu vào App Launcher và menu hệ thống.

..._amd64.AppImage Chạy Ngay (Portable)

Chạy ngay trên mọi bản phân phối Linux mà không cần cài đặt (Arch, Manjaro, Fedora, openSUSE...).

...-1.x86_64.rpm Fedora / RHEL

Dành cho Fedora, Red Hat Enterprise Linux (RHEL), openSUSE và CentOS.

Lệnh Cài Đặt Linux Nhanh
1
Gói .deb (Ubuntu / Debian)
Mở terminal tại thư mục Downloads và chạy:
sudo dpkg -i FlowGit_*.deb
2
Gói .AppImage (Mọi Linux)
Cấp quyền thực thi và mở ứng dụng:
chmod +x FlowGit_*.AppImage && ./FlowGit_*.AppImage
